# Bundled translations

Passed to `pxt staticpkg --locs-src locales` so the editor needs no network for its UI strings.

- `nb/strings.json`: our own Norwegian for the pxt editor strings a player sees most (issue #59), under this
  repository's licence. The keys are pxt's English strings (MIT). A string that is not here shows in English.
  Do not copy from makecode.com's or Crowdin's translations: nothing found allows reuse of them here.
- `nb/halisoncode/*.json`: our own block and target strings.
